# Shopware Scaffolding CLI

A CLI tool to quickly scaffold Shopware 6 plugins with various features and dev-tooling.

## Installation

You can install the package via composer:

```bash
composer require --dev tjaugust01/shopware-scaffolding
```

Or install it globally:

```bash
composer global require tjaugust01/shopware-scaffolding
```

## Usage

Run the following command to start the scaffolding process:

```bash
sws
```

Follow the interactive prompts to configure your new Shopware 6 plugin.
